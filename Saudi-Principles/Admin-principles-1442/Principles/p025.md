# ترقية

• مناط مباشرة أعمال الترقية:

لا يمكن للموظف مباشرة أعمال وظيفته المرقى عليها إلا بعد صدور قرار الترقية ومزاولته الفعلية للوظيفة.

(أ/437/1440)

## عدم سريان الترقية بأثر رجعي

صدور قرار بترقية الموظف، ومن ثم مزاولته الفعلية لأعمال الوظيفة المرقى عليها؛ يمتنع معه وفق النظام إصدار قرار الترقية بأثر رجعي.

(ب/437/1440)
